## Overview

**Problem**: Story 1.4 implemented SHA256 checksum verification (SEC-001 security fix) but uses placeholder checksums that must be replaced with real values before production deployment.

**Current State** (`samplify/utils/ffmpeg.py:45-48`):
```python
FFMPEG_SHA256 = {
    'Windows': 'PLACEHOLDER_UPDATE_WITH_ACTUAL_WINDOWS_SHA256_CHECKSUM',

    'Linux': 'PLACEHOLDER_UPDATE_WITH_ACTUAL_LINUX_SHA256_CHECKSUM'

```

**Goal**: Replace placeholders with real SHA256 checksums for production security.

## Prerequisites

**Tools Required**:
- **Windows**: Built-in `certutil` command
- **macOS/Linux**: Built-in `sha256sum` or `shasum` command
- **All Platforms**: Internet connection to download FFmpeg binaries

**Download URLs** (from `ffmpeg.py:33-37`):
- **Windows**: https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip
- **macOS**: https://evermeet.cx/ffmpeg/ffmpeg-7.0.2.zip

## Detailed Implementation Steps

### Step 1: Download FFmpeg Binaries (20 minutes)

**Choose ONE of the following approaches**:

#### Approach A: All Platforms (Recommended)

**If you have access to Windows, macOS, and Linux**:

1. **Windows**:
   ```powershell
   # Open PowerShell
   cd C:\Temp  # Or any temp directory

   # Download
   Invoke-WebRequest -Uri "https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip" -OutFile "ffmpeg-windows.zip"

   # Calculate checksum
   certutil -hashfile ffmpeg-windows.zip SHA256
   # Output: <64-character hex string>
   ```

2. **macOS**:
   ```bash
   # Open Terminal
   cd /tmp  # Or any temp directory

   # Download
   curl -L -o ffmpeg-macos.zip "https://evermeet.cx/ffmpeg/ffmpeg-7.0.2.zip"

   # Calculate checksum
   shasum -a 256 ffmpeg-macos.zip
   # OR: sha256sum ffmpeg-macos.zip
   # Output: <64-character hex string>  ffmpeg-macos.zip
   ```

3. **Linux**:
   ```bash
   # Open terminal
   cd /tmp  # Or any temp directory

   # Download
   ```

## Troubleshooting

### Issue 1: Download Fails

**Problem**: `wget` or `curl` fails to download

**Solutions**:
1. **Check internet connection**
2. **Try alternative download method**:
   - Windows: Use browser to download manually
   - macOS/Linux: Use `curl -L` instead of `wget`
3. **Verify URL is correct** (URLs may change - check ffmpeg.py for latest)
4. **Check firewall/proxy** blocking downloads

---

### Issue 2: Checksum Command Not Found

**Problem**: `sha256sum: command not found` or `certutil: command not found`

**Solutions**:

**Windows** (certutil missing - unlikely):
```powershell
# Use PowerShell alternative
Get-FileHash -Algorithm SHA256 ffmpeg.zip
```

**macOS** (sha256sum missing):
```bash
# Use shasum (always available on macOS)
shasum -a 256 ffmpeg.zip
```

**Linux** (sha256sum missing - unlikely):
```bash
# Install coreutils
sudo apt-get install coreutils  # Debian/Ubuntu
sudo yum install coreutils      # RHEL/CentOS
```

---

### Issue 3: Checksum Doesn't Match After Update

**Problem**: After updating checksums, `verify_checksum()` still fails

**Possible Causes**:
1. **Typo in checksum** - Double-check hex string (64 characters)
2. **Wrong binary downloaded** - Ensure URL matches `FFMPEG_URLS` in code
3. **Binary file corrupted** - Re-download and recalculate
4. **Checksum from wrong file** - Ensure you checksummed the ZIP/TAR file, not extracted binary

**Debug**:
```python
# Test checksum manually
python manage.py shell
>>> from pathlib import Path
>>> from samplify.utils.ffmpeg import verify_checksum, FFMPEG_SHA256
>>>
>>> # Test Windows checksum (adjust path to your download)
>>> test_file = Path("C:/Temp/ffmpeg-windows.zip")
>>> expected = FFMPEG_SHA256['Windows']
>>> verify_checksum(test_file, expected)
# Should output: True
```
